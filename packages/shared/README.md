# @sharanam/shared

Shared TypeScript contracts for mobile, admin, and API.

## Contents

| Path | Purpose |
| --- | --- |
| `src/types` | Domain & API response types |
| `src/schemas` | Zod schemas shared across boundaries |
| `src/constants` | Cross-app constants |
| `src/utils` | Tiny pure helpers |

Import via `@sharanam/shared` after `npm run build` (or workspace linking).
